# Task-track
A lightweight, no-frills to-do list app built with vanilla HTML, CSS, and JavaScript. Add, edit, complete, and delete tasks with a clean, responsive interface. No frameworks, no build tools, no dependencies. Just open index.html and start organizing.

Add and remove tasks instantly
Mark tasks complete/incomplete with a single click
Persistent state using local storage
Fully responsive, works on desktop and mobile
Zero dependencies — pure HTML/CSS/JS
